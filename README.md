# Spaceships

Een eenvoudige PHP-webapplicatie met voorbeeldcode voor de les **Webtechnologie/PHP**.

## Over dit project

Dit project is gemaakt als oefenmateriaal en demonstratie van de basisprincipes van PHP en webontwikkeling. De code laat zien hoe je een kleine webapplicatie rondom ruimteschepen kunt opzetten.

> Dit is een educatief voorbeeldproject. De code is bewust eenvoudig gehouden en is niet bedoeld voor productiegebruik.

## Technologieën

- PHP
- HTML
- CSS
- Git en GitHub

## Aan de slag

### Vereisten

Zorg dat je beschikt over:

- PHP 8.0 of hoger
- Een lokale webserver, zoals de ingebouwde PHP-server, XAMPP of Laragon
- Git, wanneer je het project lokaal wilt klonen

### Installeren

Clone de repository en ga naar de projectmap:

```bash
git clone https://github.com/RensKooijman/Spaceships.git
cd Spaceships
```

Start vervolgens de ingebouwde PHP-server:

```bash
php -S localhost:8000
```

Open daarna [http://localhost:8000](http://localhost:8000) in je browser.

## Projectstructuur

De belangrijkste bestanden en mappen vind je in de hoofdmap van het project. Bekijk de broncode om te zien hoe de pagina's, PHP-logica en eventuele gegevens met elkaar samenwerken.

## Bijdragen

Verbeteringen en suggesties zijn welkom. Maak bijvoorbeeld een fork, werk je wijziging uit in een aparte branch en open daarna een pull request.

1. Maak een branch voor je wijziging.
2. Beschrijf duidelijk wat je hebt aangepast.
3. Test de applicatie lokaal.
4. Open een pull request met een korte toelichting.
